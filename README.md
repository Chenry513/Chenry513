## What I’m currently working on

I’m currently a Mitacs Research Intern working on a robotic welding automation research project in collaboration with Seaspan Shipyards.

The broader goal of this work is to reconstruct welding joints in 3D from photos, producing geometric outputs that can support downstream robotic welding tasks. This involves building and supporting computer vision workflows and tooling that help turn raw image data into usable 3D models.

Recent work has included:
- Supporting pipelines that convert welding imagery into reconstructed 3D geometry
- Building and evaluating computer vision approaches for weld joint detection
- Collaborating with robotics and mechanical engineers to understand workflow requirements and expected outputs
- Developing supporting tools and documentation to help teams inspect and use model results, including WeldPath Viz (https://chenry513.github.io/weldpath-viz/visualize_weld.html), a browser-based viewer that allows engineers to explore reconstructed point clouds, define weld start and end points, and extract coordinates for downstream robotic execution
